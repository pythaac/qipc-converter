QIPC Converter — Windows 10/11 (64비트)

1. QIPCConverter.exe를 더블클릭합니다. Python, FFmpeg를 별도로 설치할 필요가 없습니다.
2. 위쪽 입력 영역에 BIN 파일 또는 폴더를 놓습니다. ‘파일 찾기’와 ‘폴더 찾기’도 사용할 수 있습니다.
   폴더는 하위 폴더의 BIN까지 포함합니다. 같은 경로를 다시 추가해도 목록에 중복되지 않습니다.
3. 아래쪽 출력 영역에 저장할 폴더를 놓거나 ‘폴더 찾기’로 선택합니다.
   출력 영역에 파일을 놓으면 그 파일의 상위 폴더가 선택됩니다.
4. ‘변환하기’를 누릅니다. 전체 진행률과 현재 파일의 추출·MP4 생성·검사 진행률을 확인합니다.
5. 완료 후 ‘출력 폴더 열기’를 누릅니다.

출력 이름은 Windows 탐색기의 ‘수정한 날짜’(현재 PC의 현지 시각)를 기준으로 합니다.
예: 2025-04-04_19-21-26.mp4
이름이 겹치면 2025-04-04_19-21-26_2.mp4, _3.mp4로 저장합니다. 기존 파일을 덮어쓰지 않습니다.
입력 폴더 구조와 관계없이 선택한 출력 폴더에 MP4 파일을 각각 저장합니다.

결과는 원본 해상도 HEVC(H.265) 영상 + 원본 AAC 음성의 MP4 하나입니다.
영상 재인코딩이나 크기 변경을 하지 않습니다. HEVC를 지원하는 재생기를 사용하세요.
저장된 구간의 프레임 속도를 자동 판별해 연결하며 녹화 공백은 제외합니다. 화면의 촬영 시각은 유지됩니다.
한 파일에서 15fps와 20fps가 바뀌는 경우에도 각 구간의 재생 속도를 유지합니다.
전체 영상·음성 검사를 통과한 파일만 최종 이름으로 저장합니다. 검사 단계는 시간이 걸릴 수 있습니다.
BIN 원본은 수정하거나 삭제하지 않습니다. 임시 파일은 처리 후 정리합니다.

‘현재 파일 후 중지’는 현재 파일을 완료한 뒤 다음 파일부터 작업하지 않습니다.
실패한 파일은 목록과 아래 기록에 표시하며 나머지 파일은 계속 처리합니다.
실행 중 PC를 절전하거나 USB/외장 저장장치를 분리하지 마세요.

지원 범위: 이번에 확인한 QIPC의 단일 채널 HEVC/AAC 블록 저장 형식.
임의의 다른 BIN 파일, 암호화된 녹화, 다른 기종의 저장 형식은 지원하지 않을 수 있습니다.
Windows 10/11 x64 및 .NET Framework 4.8 환경용입니다. macOS용은 포함하지 않습니다.
